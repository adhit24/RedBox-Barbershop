## CRM → REDDY CUSTOMER INTELLIGENCE (PLAN B — REDDY INTELLIGENCE CORE)

---

## Task 1: Create `server/agents/reddy/customerFactsContext.js`
- Implement `extractCustomerIntelligenceEnvelope(crmResult, intent)` helper:
  - Takes raw `crmAgent` execution result under `CUSTOMER_SELF` projection.
  - Builds safe Customer Intelligence Envelope:
    `facts`: `name`, `registration_status`, `membership_tier`, `points_balance`, `first_visit`, `last_visit`, `favorite_branch`, `favorite_barber`, `favorite_service`.
    `unknown_fields`: list of fields that are null/unknown.
  - Ensures forbidden fields (`id`, `moka_customer_id`, `notes`, `spending`, `lifetime_spend`, `phone`, `user_id`) are 100% stripped and absent.
- Implement `buildCustomerFactsContext(envelope)` helper:
  - Formats structured system prompt section demarcated by `CUSTOMER FACTS — TRUSTED CRM DATA`.
  - Lists available facts and explicitly lists unknown fields.
  - Adds system enforcement rules preventing hallucination of missing values.

---

## Task 2: Update `server/orchestrator/executionService.js`
- Create `executeCustomerIntelligence({ intent, action, trustedIdentity }, dependencies)` function:
  - Requires valid `trustedIdentity` (fails closed as `unauthorized` if missing/invalid).
  - Enforces CRM tool allowlist:
    * `points_inquiry` $\rightarrow$ `get_points`
    * `customer_history` $\rightarrow$ `get_customer_history`
    * `customer_profile` $\rightarrow$ `get_customer_profile`
    * `customer_preferences` $\rightarrow$ `get_customer_preferences`
    * `membership` / `customer_membership` $\rightarrow$ `get_membership`
  - Rejects unsupported intents as `unsupported_intent`.
  - Invokes `executeCrmTool(toolName, {}, { phone: trustedIdentity.phone, customer_id: trustedIdentity.customer_id, projection: 'CUSTOMER_SELF', supabase })`.
  - Converts result into Customer Intelligence Envelope via `extractCustomerIntelligenceEnvelope`.

## Task 3: Update `server/agents/reddy/reddyAdapter.js`
- Update `executeReddyAgent(params, dependencies)` to accept optional `customerIntelligence` in `params`.
- If `customerIntelligence` is present and `status === 'success'`, invoke `buildCustomerFactsContext(customerIntelligence)` and pass facts context into prompt builder.

## Task 4: Update `api/wa/webhook.js`
- Update `handleMessage` for `route === 'crm_agent'`:
  - `points_inquiry`: preserve 0-LLM deterministic path (`used: 'crm_points'`).
  - Untrusted request (`!trustedIdentity`): return `used: 'crm_privacy_guard'` (`"Halo kak! Untuk mengecek saldo poin member RedBox..."`).
  - Trusted request with supported personalized intent (`customer_history`, `customer_profile`, `customer_preferences`, `membership`):
    - Execute `executeCustomerIntelligence({ intent: orchDecision.intent, action: orchDecision.action, trustedIdentity, supabase: getSupabase() })`.
    - If success: execute `executeReddyAgent` with `customerIntelligence: intelRes.intelligence`.
    - Return `used: 'crm_reddy_intelligence'`, reply generated by Reddy with trusted facts.
  - Trusted request with unsupported intent: return `used: 'crm_unavailable_guard'` (`"Untuk data pribadi selain poin, fitur ini masih sedang kami siapkan ya kak."`).
