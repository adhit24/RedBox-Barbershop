1. Page Transition — Slide Horizontal
ENTER (forward)
initial: x: "100%", opacity: 0
animate: x: 0, opacity: 1
spring: stiff 300, damp 30
duration: ~350ms
ENTER (back)
initial: x: "-100%", opacity: 0
animate: x: 0, opacity: 1
spring: stiff 300, damp 30
duration: ~350ms
EXIT (forward)
exit: x: "-30%", opacity: 0
easing: ease-in 200ms
Tidak full slide — hanya 30% ke kiri
supaya tidak terlalu keras
EXIT (back)
exit: x: "30%", opacity: 0
easing: ease-in 200ms
Slide ke kanan sedikit
+ fade out

PageTransition.tsx — Kode Inti
const variants = {
  enter: (dir) => ({ x: dir === 'forward' ? '100%' : '-100%', opacity: 0 }),
  center: { x: 0, opacity: 1 },
  exit: (dir) => ({ x: dir === 'forward' ? '-30%' : '30%', opacity: 0 }),
}

return (
  <AnimatePresence mode="wait" custom={direction}>
    <motion.div key={pathname} custom={direction}
      variants={variants}
      initial="enter" animate="center" exit="exit"
      transition={{ type: 'spring', stiffness: 300, damping: 30 }}
    >
      {children}
    </motion.div>
  </AnimatePresence>
)
