# Impeccable Design Context

## Design Context

### Users
Barbershop chain owners (RedBox Barbershop) and branch admins operating the "RedBox Stockist" inventory module inside the existing RedBox admin portal. Owners check the dashboard on the go (mostly phone, sometimes desktop browser at the same 430px width) between other tasks — quick situational reads, not long sessions. They're not designers or power users; they're operators who need to know "what needs my attention right now" and jump straight to it.

### Brand Personality
Premium, Bold, Dark, Trustworthy, Operational, Efficient, Modern, slightly industrial but still approachable. (Source: `design_STOCKIST.md` Brand Direction.) Every screen should answer one question fast: **"Apa yang perlu saya lakukan sekarang?"** (What do I need to do now?).

### Aesthetic Direction
- Reuse the existing RedBox Stockist dark premium system — do NOT introduce new fonts, new color tokens, or a new visual language. This is one screen inside an already-shipped module, not a new product.
- Theme: dark only (fixed, from `globals.css` `--color-surface-*`, `--color-primary-container: #c72820`, etc.).
- Typography: Plus Jakarta Sans (display/headings) + Inter (body) — already loaded globally, keep as-is.
- Icons: Material Symbols Outlined, `FILL` toggled for active/emphasis states, as used throughout the module.
- Layout constraint: mobile-first, hard-capped `max-w-[430px]` shell (header + bottom nav + content), matches the rest of the stockist app.
- Anti-references: no side-stripe (`border-left`) accent cards, no gradient text, no glassmorphism, no decorative sparklines, no repeated identical bordered-card grids — avoid the "AI dashboard slop" look even while staying inside the existing token system.

### Design Principles
1. One clear job per screen: surface what needs action, let calm state stay quiet.
2. Company-wide, not branch-scoped — owner's command center reasons across all 6 locations at once, never mixes warehouse and branch figures into one number.
3. Read-only + link-out: the command center itself never mutates data; every actionable item is a link to the page that owns that action.
4. Severity through color and position, not borders: use the existing `--color-danger` / `--color-warning` / `--color-success` tokens via text/background/icon treatment, not stripe accents.
5. Consistency over novelty: extend the existing dark premium system precisely rather than reinventing it for this one screen.
